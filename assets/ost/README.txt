OST DUNIA — PRISMA WORLDS
=========================

Taruh file musik milikmu di folder ini dengan nama angka, sesuai nomor dunia:

    1.mp3 -> Dunia 01  Taman Seroja
    2.mp3 -> Dunia 02  Area Server
    3.mp3 -> Dunia 03  Hutan Kaca
    4.mp3 -> Dunia 04  Pesisir Nebula
    5.mp3 -> Dunia 05  Orbit
    6.mp3 -> Dunia 06  Kota Prisma
    7.mp3 -> Dunia 07  Pameran Seni
    8.mp3 -> Dunia 08  Taman Hiburan
    9.mp3 -> Dunia 09  Stasiun Helios

Aturan:
- Format yang didukung: .mp3 (disarankan). Format lain yang bisa diputar
  browser (mis. .ogg/.m4a) juga bisa, asal ekstensinya diganti sesuai file.
- Satu dunia = satu file, diputar berulang (loop).
- Kalau filenya tidak ada, game otomatis memakai suara ambient bawaan,
  jadi tidak ada pesan error — tinggal tambahkan file kapan saja.
- File terdeteksi otomatis tanpa perlu reload halaman? Untuk amannya,
  reload sekali setelah menambah/mengganti file (hasil deteksi di-cache).

Cara cepat: seret file musik ke folder ini lalu ganti namanya menjadi
angka sesuai dunia (1 sampai 9), lalu refresh halaman game.
